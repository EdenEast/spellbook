# Guard the context window

## Rule

Keep active context focused on evidence needed for the current decision.

## When to use

Large artifacts, verbose output, repeated reads, or long tasks threaten to bury
useful information.

## How to apply

1. Search narrowly and read relevant sections. Bound command output and inspect
   truncation before relying on incomplete results.
2. Save large artifacts outside active context when useful. Keep summaries with
   source locations, decisions, uncertainties, and next checks.
3. Keep universally needed guidance near its loading point. Disclose
   branch-specific detail through precise pointers.
4. If delegation is permitted and worthwhile, assign bounded reading tasks and
   request cited findings rather than raw payloads.

## Boundaries

Delegation is optional and follows active instructions. Summaries can lose
exceptions; return to the source for consequential decisions. Preserve necessary
evidence even when it costs context.

## Check

Can the next step find evidence and constraints without repeating bulk reads?
Are summary claims traceable to sources?
