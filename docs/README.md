# Spellbook documentation

- [User documentation](user/README.md): install Spellbook, use its resources,
  and set up a development environment.
- [Agent documentation](agents/README.md): maintain skills, references, source
  records, and repository structure.
- [Shared glossary](GLOSSARY.md): domain terms used by both audiences.

Put setup and usage explanations in `user/`. Put agent maintenance procedures
in `agents/`. Keep shared definitions in the glossary and link across audiences
when needed rather than duplicating guidance.

Return to the [project README](../README.md) for the first install commands.
